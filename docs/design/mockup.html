Write a Rust function that retries an async operation with exponential backoff, max 5 attempts.

Here's an idiomatic version using tokio. It doubles the delay each attempt and gives up after the fifth try:

rustCopy
use std::time::Duration;

pub async fn retry_backoff<F, Fut, T, E>(mut op: F) -> Result<T, E>
where
    F: FnMut() -> Fut,
    Fut: std::future::Future<Output = Result<T, E>>,
{
    let mut delay = Duration::from_millis(100);
    for attempt in 1..=5 {
        match op().await {
            Ok(v) => return Ok(v),
            Err(e) if attempt == 5 => return Err(e),
            Err(_) => {
                tokio::time::sleep(delay).await;
                delay *= 2; // exponential

The bound FnMut lets you call op again each loop
