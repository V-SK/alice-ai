# Alice AI — backend dependencies.
#
# Dependency direction (PLAN §2.4): alice-ai/backend depends on alice-acp (our
# Track-A inference engine) as a normal Python package — we CONSUME it, never
# fork/copy. It is wired here as an editable PATH dependency to the sibling repo.
#
# M0 scope: only what the import smoke needs must actually install — the
# `alice-acp` package (so `from alice_acp.local_inference import ...` resolves)
# plus odysseus's web stack. The heavy inference wheels (llama-cpp-python, mlx,
# onnx via fastembed) are DECLARED here but DEFERRED to M1/M4 — they are large,
# platform-specific, and not needed to make the imports resolve. See the
# "DEFERRED" block and the heavy-dependency note at the bottom.
#
# A hash-pinned `requirements.lock.txt` is produced in a later milestone (M2+);
# this file pins loosely for the dev env.

# =============================================================================
# 1. Our inference engine — alice-acp (editable path dep). REQUIRED for M0.
# =============================================================================
# `local_inference` and its transitive alice_acp.* imports (api_chat,
# api_chat_gateway, mining_device) are PURE-STDLIB at import time, so this brings
# in only alice-acp's own light hard deps (alembic, cryptography, psycopg,
# SQLAlchemy). The MLX/llama.cpp adapters in runtimes.py import their backends
# LAZILY, so neither is required just to import the package.
#
# NOTE: this path is relative to THIS file's directory (backend/), so install
# from inside backend/  (`cd backend && pip install -r requirements.txt`) — or
# just use scripts/setup_dev_env.sh, which does that. pip resolves relative
# requirement paths against its CWD, not the -r file's location.
-e ../../alice-acp

# =============================================================================
# 2. odysseus web stack — the forked FastAPI app. REQUIRED for M0/M1.
#    (subset of backend/odysseus/requirements.txt: just enough to import app.py)
# =============================================================================

# =============================================================================
# 3. odysseus core-path libs (RAG/research/calendar). Installed by default
#    upstream; kept here so app import doesn't trip a hard import. Light-ish.
#    (Trim happens at freeze time per PLAN §2.3 — Advanced-only deps dropped.)
# =============================================================================

# =============================================================================
# 4. M1 SPINE — inference runtime + native shell + model download. REQUIRED for
#    the end-to-end local chat (PLAN M1). These are heavier; on macOS arm64 the
#    inference backend is MLX (Apple-optimised). llama-cpp-python (CPU/CUDA GGUF)
#    stays DEFERRED below — it is the Windows/Linux backend, dropped here.
# =============================================================================
# Apple-Silicon inference (this box). Marker-gated so a non-arm64 macOS / other
# OS install does not try to pull MLX (which is macOS-arm64 only).
mlx ;     sys_platform == "darwin" and platform_machine == "arm64"
mlx-lm ;  sys_platform == "darwin" and platform_machine == "arm64"
# Model weights download (first-run fetch of Alice Lite to ~/.alice/models).
huggingface_hub
# The native PyWebView shell (shell/alice_shell). System WebView; no extra GUI dep.
pywebview

# 5. odysseus runtime deps that app.py imports at module load (so the forked
#    FastAPI boots from source). These are Advanced-gated features whose hard
#    imports must resolve; their heavy/networked behaviour is off by default and
#    they are trimmed from the frozen build (PLAN §2.3). RAG embeddings
#    (fastembed/chromadb) stay DEFERRED — the app fail-softs to no-vector-memory.
# =============================================================================

# =============================================================================
# HEAVY-DEPENDENCY NOTE (for the later bundling milestones)
# =============================================================================
# `alice_acp.local_inference` itself needs NO heavy deps to import or to run the
# StubRuntimeAdapter — it is pure stdlib, and MLX/llama.cpp are imported lazily
# only when a real adapter is selected. So the bundle does NOT need alice-acp's
# FULL dependency tree (alembic/psycopg/SQLAlchemy are pulled by other alice_acp
# subpackages, not by the inference path). At freeze time we can collect just:
#   alice_acp.local_inference  + its intra-package deps:
#     alice_acp.api_chat.{contracts,model_catalog,types,validators}
#     alice_acp.api_chat_gateway.{colocated_inference_worker,worker_bridge}
#     alice_acp.mining_device.{detector,types}
# plus exactly one inference backend wheel for the target platform
# (mlx+mlx-lm on macOS arm64; llama-cpp-python CPU/CUDA on Win/Linux).
